## 已有能力

| 能力 | 当前支持 | 边界 |
|---|---|---|
| 六个 skills 独立分发 | 调度、受控协议、四类宿主字典，以及完整的脚本和参考资料 | 无需额外管理仓库；宿主 CLI、认证和终端传输单独安装 |
| herdr 页面组织 | 当前发布版默认新 workspace、可选新 tab、任务标题与父页面焦点保留 | 已记录改为同 space 默认新 tab、标题含 agent 类型的需求，尚未实现；页面不隔离文件系统，viewer 仍需验收 |
| 提交和恢复 | run/job/round、唯一活动轮、提交 uncertain、租约、跨 watch 待办、分页摘要及可选增量续读 | uncertain 需核对实际证据，不能自动重发；delta 复用源内容，仍扫描目录与验证元数据 |
| 并行监督 | 提交前建立观察、工作预算、提前续接边界、权限画面复核、持久处理回执及可选业务日志检查点等待 | 不会唤醒已结束的调度会话；原生审批 30 秒响应目标仍未通过 |
| 独立交付验证 | 源码快照、独立验收、返工和原生宿主收尾门禁 | 验收内容仍须根据具体任务设计 |
| 用量审计 | 原生来源导入、不可变纠正、轮次选择与来源绑定 | 不保证所有隐式后台调用均被记录 |
| Hermes | 原版宿主编排、可选主循环用量插件、原生累计只读视图及前置诊断 | 辅助逐调用、轮次归属与全宿主完整计量仍有缺口 |

OpenCode/OMO 等字典保留已核对版本及配置相关的兼容说明，用作适配参考；读者应核对自己的版本、插件和实际角色列表，不照搬另一环境的默认配置。运行包不携带模型凭据或个人配置。

## 可复现验证

正式回归入口在[测试说明](../tests/README.md)。默认执行不调用模型；真实 tmux 测试需要显式启用以及本地 socket 权限。2026-09-21 在 Linux、Python 3.14.7 下验证本公开快照：**492 项全部通过，含 13 项真实 tmux 测试，零跳过/失败**。终端测试使用自有临时 socket，在允许本地 socket 的环境中执行；回归没有新模型调用。C1 新增 12 项检查，C2 新增 18 项；规模与边界见[恢复摘要验证](C1-RECOVERY.md)及[增量恢复验证](C2-RECOVERY.md)。B1 另做了真实 omp/Codex 长时实验并新增四项恢复目录回归，详见[监督实测与未通过项](B1-SUPERVISION.md)。B2 新增 18 项回归，完成独立应用和一次短原生验证；[B2 报告](B2-SUPERVISION.md)保留未达标时效和初始观察器到期记录。

分发包检查为 6 个 skills、30 份 Markdown、141 个本地链接、零发现。公开树另做了本地链接解析、Bash 示例语法及个人路径/明显凭据模式检查；合成测试值保留。该内容审阅使用有限规则和人工核对，不是完整的自动密钥检测证明。

CI 配置覆盖 Python 3.10–3.14；配置存在不等于远端任务已通过。可选宿主探针和实际模型 E2E 需单独执行。包内链接检查也不是全部宿主行为已验收的证明。

## 主线顺序：C → B → E

| 顺序 | 工作 | 当前状态 | 验收要求 |
|---|---|---|---|
| C | 精简恢复输出与增量读取 | C1/C2 首版完成：summary 分页；delta 复用源内容并按变化续读，待办/错误/健康每次返回 | 已比较 1/10/50/100 任务的完整/摘要/增量；验证权限、waiting_user、未知健康、部分失败、游标失效与仅随时间发生的过期；缓存自身 I/O 单独计量，未宣称普遍加速 |
| B | 长时并行监督、审批与恢复 | B1 长时实测后，B2 检查点等待、stdin 发布、60 秒续接余量及旧 blocked 复核已实现；短原生功能通过，审批响应仍超 30 秒 | 进入用户真实项目复测，保留完整时序；长期多宿主处置、重叠接续与写入范围继续验收，不把工具实现或单次功能通过当作整个 B 完成 |
| E | 同任务单／多 agent 对照 | 待前置完成 | 相同任务和验收，计入调度方、子任务、后台、重试与返工；比较质量、token、墙钟时间、等待和波动 |

下一主线仍为 B：B2 本批实现已交付，DataHive 实测后的修复、计量、审批与接班按综合计划分批推进，再进入 E 的受控对照；不再仅等待用户继续实测。`recover --summary` 与 `supervision.py` 仍读取完整 recover；delta 缓存只减少源内容重复读取和行输出，目录扫描、元数据检查、JSON 验证及时间判断继续执行，并写入私有游标，尚非常数成本查询。默认完整 recover 的 `--limit` 仍只分页待办。摘要或 delta 健康计数均不替代监督检查。输出字节数不能直接换算为 token 或费用，当前没有多 agent 净节省 token 的结论。
