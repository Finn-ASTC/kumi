# kumi 状态与路线

本页区分已有机制、可复现检查和仍待验证的行为。普通接入从[部署说明](../INTEGRATION.md)开始；运行包使用 schema version 1 的轮次契约。

## 已有能力

| 能力 | 当前支持 | 边界 |
|---|---|---|
| 六个 skills 独立分发 | 调度、受控协议、四类宿主字典，以及完整的脚本和参考资料 | 无需额外管理仓库；宿主 CLI、认证和终端传输单独安装 |
| herdr 页面组织 | 默认新 workspace、可选新 tab、任务标题与父页面焦点保留 | 页面不隔离文件系统；桌面 viewer 交互仍需进一步验收 |
| 提交和恢复 | run/job/round、唯一活动轮、提交 uncertain、租约与跨 watch 待办 | uncertain 需核对实际证据，不能自动重发 |
| 并行监督 | 提交前建立观察、工作预算、权限画面检查、持久处理回执 | 不会唤醒已结束的调度会话；30 秒响应目标长期达标待验证 |
| 独立交付验证 | 源码快照、独立验收、返工和原生宿主收尾门禁 | 验收内容仍须根据具体任务设计 |
| 用量审计 | 原生来源导入、不可变纠正、轮次选择与来源绑定 | 不保证所有隐式后台调用均被记录 |
| Hermes | 原版宿主编排、可选主循环用量插件、原生累计只读视图及前置诊断 | 辅助逐调用、轮次归属与全宿主完整计量仍有缺口 |

OpenCode/OMO 等字典保留已核对版本及配置相关的兼容说明，用作适配参考；读者应核对自己的版本、插件和实际角色列表，不照搬另一环境的默认配置。运行包不携带模型凭据或个人配置。

## 可复现验证

正式回归入口在[测试说明](../tests/README.md)。默认执行不调用模型；真实 tmux 测试需要显式启用以及本地 socket 权限。2026-09-20 在 Linux、Python 3.14.7 下验证本公开快照：**440 项全部通过，含 13 项真实 tmux 测试，零跳过/失败**。终端测试使用自有临时 socket，在允许本地 socket 的环境中执行；没有新模型调用。

分发包检查为 6 个 skills、29 份 Markdown、134 个本地链接、零发现。公开树另做了本地链接解析、Bash 示例语法及个人路径/明显凭据模式检查；合成测试值保留。该内容审阅使用有限规则和人工核对，不是完整的自动密钥检测证明。

CI 配置覆盖 Python 3.10–3.14；配置存在不等于远端任务已通过。可选宿主探针和实际模型 E2E 需单独执行。包内链接检查也不是全部宿主行为已验收的证明。

## 主线顺序：C → B → E

| 顺序 | 工作 | 当前状态 | 验收要求 |
|---|---|---|---|
| C | 精简恢复输出与增量读取 | 待实现；`recover --limit` 目前只分页待办，仍返回全部任务/轮次/watch | 在 1/10/50/100 任务下比较完整、摘要和增量输出；权限、waiting_user、读取失败、未知健康与游标失效仍可见 |
| B | 长时并行监督、审批与恢复 | 已有机制和确定性回归，长时原生验收待补 | 控制器有独立产物、兄弟任务同时推进；多次真实审批、观察器接续、上下文恢复；量化发现→处理→记账延迟 |
| E | 同任务单／多 agent 对照 | 待前置完成 | 相同任务和验收，计入调度方、子任务、后台、重试与返工；比较质量、token、墙钟时间、等待和波动 |

`supervision.py` 已有精简展示，但内部仍读取完整 recover，尚非增量或常数成本查询。输出字节数不能直接换算为 token 或费用。当前没有多 agent 净节省 token 的结论。

## 独立跟进

- Hermes 原生扩展／Relay：先解决只记录数值的观察器、可信身份映射，再验证异步、流式、重试、嵌套、后台和退出投递；日常安装不启用 Relay。
- Hermes 原生错误／重试：补真实 provider 错误路径；确定性模拟不代替现场覆盖。
- 结果发布：进一步约束临时文件位置，优先使用现有 write-result helper 和同目录原子发布，并核对副作用。
- herdr 桌面 viewer：补 space/tab 切换、名称、可见性和焦点交互验收。

本项目目前适合有持续监督责任的本地协作，不提供完整的无人值守调度服务。
